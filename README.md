## 🚀 Quick Start

```bash
# Clone repository
git clone https://github.com/spacewink9/spacewinkgis-vue-project.git
cd spacewinkgis-vue-project

# Install dependencies
npm install

# Start development server
npm run dev

# Open http://localhost:3000
```
